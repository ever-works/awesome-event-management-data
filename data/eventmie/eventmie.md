## Overview

Eventmie is an open-source self-hosted Eventbrite alternative. It allows users to run their own events business on their own hosting and domain, functioning as both an event ticket selling website and an event management platform.

## Features

- Open-source self-hosted event management
- Event ticket selling capabilities
- Eventbrite alternative
- Runs on your own hosting and domain
- PHP-based platform

## Deployment

Self-hosted
