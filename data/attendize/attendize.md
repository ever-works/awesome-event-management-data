## Overview

Attendize is an open-source ticket selling and event management platform built on Laravel. It is designed for selling event tickets and managing event registrations on a self-hosted basis.

## Features

- Open-source ticket selling platform
- Built on Laravel PHP framework
- Self-hosted deployment
- Event management and attendee tracking
- Ticket sales and registration management

## Deployment

Self-hosted
