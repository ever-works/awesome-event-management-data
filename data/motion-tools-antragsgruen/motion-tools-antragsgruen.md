# motion.tools (Antragsgrün)

## Overview

motion.tools (also known as Antragsgrün) is a self-hosted web application for managing motions and amendments for political conventions.

## Features

- Manage motions and amendments
- Support for political conventions

## Technology

- PHP
- Docker support
