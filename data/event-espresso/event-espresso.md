## Overview

Event Espresso 4 Core is a WordPress plugin for building event ticketing websites. It enables users to sell event tickets and manage event registrations directly from their WordPress site.

## Features

- WordPress plugin for event ticketing
- Sell event tickets directly from WordPress
- Event registration management
- Core plugin for Event Espresso platform

## Deployment

Self-hosted (WordPress plugin)

## Pricing

Paid (WordPress plugin with core and add-on options)
